# Foley Collective brand assets

## Approved favicon and compact brand mark

The owner supplied `TheTransparentCoin.png` on October 12, 2026 and requested that it be added to the branding files and replace the favicon throughout the website. The original 432 × 432 transparent PNG is preserved unmodified in the shared project files and in `public/brand/TheTransparentCoin.png`.

The site's root layout applies this asset's derived browser and touch icons to the homepage, contact page, privacy page, and not-found experience. A versioned ICO URL and new coin-specific PNG filenames avoid reusing the old favicon's browser cache. Direct `/favicon.ico`, `/favicon.png`, and `/apple-touch-icon.png` paths are also supplied for browsers that look for default filenames. The prior `/brand/foley-icon.png` path now contains the coin for compatibility.

The multi-resolution ICO contains 16, 32, and 48 pixel sizes. PNG variants are 32, 180, and 192 pixels square. These are proportional downscales that preserve transparency and the complete artwork; no original artwork was overwritten, redrawn, or recolored. The platform's compact project branding also uses the coin image. The existing horizontal wordmark in the header/footer is unchanged.

## Original wordmark assets

The ten original AI, EPS, PDF, PNG, and JPG wordmark assets remain in the shared project files and the previously delivered legacy vault. The new coin is a current brand asset, not retired website content, so it is included in the updated brand-assets package rather than inserted into the historical legacy-site archive.
